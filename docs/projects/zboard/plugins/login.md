# 使用登录插件

第三方账号登录是可选扩展。插件对接身份提供方，ZBoard 核心负责本地账户、绑定关系、登录会话和站点注册策略；支持哪些平台以所选插件的说明为准。

## 配置流程

1. 按[安装指南](./marketplace)安装支持身份提供方的插件。
2. 在对应身份平台创建应用，取得客户端标识和密钥。
3. 在插件配置页填写参数，将页面给出的回调地址原样登记到身份平台。核心回调路径为 `/api/v1/auth/oidc/callback`，前面的域名必须是你自己的公开 HTTPS 站点地址。
4. 保存配置并测试，核对公开地址、反向代理和实际访问域名一致；密钥不要写进公开文档或截图。
5. 启用插件及所需提供方，用退出登录的浏览器实际完成一次授权登录。配置测试通过不能代替真实账号验证。

一个插件可以提供多个登录入口，但不是所有插件都支持同样的平台或配置字段。按插件自己的说明配置，不要复制其他站点或提供方的回调地址。

## 已有用户与新用户

- **已有账户**：先用原来的方式登录，再在账户安全相关页面确认当前密码并绑定第三方身份。同邮箱的第三方账号不会自动合并到本地账户。
- **新用户**：仍受站点注册开关控制。提供方没有返回已验证邮箱时，需在完成页补充邮箱并验证，站点邮件服务必须可用。
- **仅用第三方注册的账户**：默认没有本地密码。刚完成第三方登录后，可在“账户安全”设置初始密码；证明五分钟后过期，届时重新登录再设置。解绑前先确保有可用的本地登录方式。
- **服务权限**：登录成功不代表已获得订阅或节点权限，仍由本站分配的订阅与授权决定。

站点关闭注册后，已绑定的正常账户仍可登录，未绑定的新身份不能借插件注册。停用插件不会删除已有账户和绑定，但会使其第三方入口不可用；维护前请保留可用的管理员本地登录方式。

## 排查方向

- 没有入口：检查插件和提供方是否启用、配置是否保存。
- 回调失败：逐字核对公开 HTTPS 地址、回调路径、客户端标识和提供方授权设置。
- 邮箱验证失败：检查邮件服务、邮箱是否已注册及授权是否超时；过期后重新发起授权。
- 更新或重启后授权失效：重新从本站登录页发起，不要反复使用旧回调链接。

查看插件测试、操作记录和登录页提示时，分享错误信息前移除密钥、授权码、Cookie 与令牌。开发者需要协议约定时，阅读[身份接口契约](./identity-reference)。
