# 插件与市场

插件让你按需扩展自托管的 ZBoard，例如增加第三方登录、额外页面、后台任务或服务提供方。基础的节点、用户和订阅管理不要求安装插件；只安装自己需要且信任的扩展。

::: info 适用版本
本组说明按 [v0.0.2-rc.202609291405](https://github.com/zerodenet/zboard/releases/tag/v0.0.2-rc.202609291405) 核对。0.0.1 正式版不包含插件入口；先在面板“关于”中核对版本。RC 是候选版，升级前请备份并阅读发布说明。
:::

## 核心和插件分别负责什么

核心管理账户、节点、订阅、访问凭证、流量，以及已实现的订单与权益规则。插件按宿主开放的权限扩展功能，不能随意访问核心数据库或绕过账户、幂等和审计规则。

例如，第三方登录插件验证外部身份，核心决定注册、绑定和签发会话。支付渠道对接属于扩展集成范围；这不表示面板已经内置支付渠道，也不表示安装任意插件就能收款。涉及支付时，以所选集成的说明和实际可用接口为准。

## 已开放的扩展范围

当前版本提供以下扩展入口，具体插件只获得其声明并通过宿主校验的部分能力：

- 公开端、用户端和管理端页面，以及指定位置的页面组件。
- 插件自己的配置与加密私有数据，可分别限制读取和写入。
- 身份提供方、声明的 HTTP 路由、后台任务、DNS 与证书提供方。
- 按当前用户或管理员身份限制的账户、订阅、消息与用量操作；订阅配额、期限和取消操作分别受专用权限约束。
- 用户自己的订单读取；支付事实写入属于另行授权的外部集成接口，不开放给浏览器插件页面。

默认市场提供已收录插件的发现、版本选择和安装入口，不必先搭建自己的目录。可用版本与平台以市场详情为准；被收录也不等于插件适合你的部署或具备操作系统级隔离。安装前阅读[信任说明](./trust)。
