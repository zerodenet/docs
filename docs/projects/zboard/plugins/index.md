# 插件与市场

节点、用户和订阅管理不要求安装插件。先完成[第一条线路](../guides/)，需要第三方登录或其他额外功能时，再添加自己信任的扩展。

## 从哪里开始

**[安装、配置和管理插件 →](./marketplace)**

需要第三方账号登录时，安装后继续[登录插件配置](./login)。默认市场可直接查找和选择已收录插件，不必先搭建自己的目录。

## 核心和插件分别负责什么

核心管理账户、节点、订阅、访问凭据、流量，以及已实现的订单与权益规则。插件使用宿主开放的接口增加能力，不能绕过账户、权限、幂等或审计规则。

例如，登录插件验证外部身份，核心处理注册、绑定和会话；支付渠道需要相应集成及实际配置，安装面板或任意插件不等于已经可以收款。

## 已开放的扩展范围

扩展可以提供页面、身份登录、后台任务、DNS/证书集成，以及获准的账户、订阅、消息与用量操作。安装预览和插件详情会显示该插件需要的具体能力。

安装前看[来源与信任](./trust)，停用、卸载或恢复前看[数据保留规则](./governance)。原生服务插件不是操作系统沙箱，只安装可信来源。

贡献插件时再读[开发与发布约定](./development)。
