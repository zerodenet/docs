# ZBoard

<ProjectMeta project-id="zboard" />

ZBoard 是面向自用与分享的 Zero 代理服务管理面板，以简单易用和低资源占用为目标。用一个 Web 控制台管理自己的服务器、线路、订阅和用量；节点上的 Zero 负责实际代理连接。商业化等额外能力通过插件按需添加，实际资源占用取决于部署与使用规模。

## 从这里开始

**[从零搭建第一条可用线路 →](./guides/)**

一篇教程完成面板部署、管理员初始化、节点接入、订阅分配和客户端连接。已经拿到账户和订阅，只想连接客户端的用户，可以直接看[获取订阅](./guides/subscriptions-and-traffic#客户端导入)。

## 日常使用 {#基础能力}

用通后，按需要[分享给其他人](./guides/daily-operations)、[添加转发入口](./guides/network-fronting)或[安装插件](./plugins/)。遇到问题先查[故障排查](./guides/troubleshooting)。
