# 我该用哪个项目？

选择你要完成的事，然后直接跟着一份完整教程开始。三个项目可以独立使用，不需要把它们全部装上。

| 你想做什么 | 用哪个工具 | 开始操作 |
| --- | --- | --- |
| 已有订阅或配置，想在电脑上连接 | **ZNet Sink**：桌面客户端 | [从安装到第一次连接](/projects/znet-sink/guides/first-connection) |
| 用配置文件在电脑或服务器上运行代理 | **Zero Core**：代理内核 | [运行第一个代理](/projects/core/guides/quickstart) |
| 集中管理自己的节点，给自己或他人分享线路 | **ZBoard**：基础面板 | [从部署到第一条可用线路](/projects/zboard/guides/) |

## 它们如何配合

Zero Core 负责实际连接和转发；ZNet Sink 负责本机的配置与操作界面；ZBoard 负责服务器、用户和订阅管理。

只有订阅时，从 ZNet Sink 开始即可。需要自己管理节点和分享账户时，再使用 ZBoard。想了解完整搭配方式，可以看[项目如何配合使用](/solutions/)。
