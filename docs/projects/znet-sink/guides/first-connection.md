# 完成第一次连接

本页的目标是先让浏览器通过代理访问网站。你需要已经[安装客户端和 Zero 内核](./installation)，并有一条订阅链接或 Zero JSON 配置文件。

**先切换到专业模式。** 可以在标题栏或设置中切换。这样能单独开启系统代理，暂时不启用需要系统权限的 TUN。切换界面模式本身不会关闭已有代理。

## 1. 准备代理配置

有订阅链接时：

1. 打开“订阅”，点击“新增”。
2. 填写名称和订阅 URL，格式先保留“自动检测”。
3. 保存后点击该订阅的同步按钮，等待成功。
4. 回到“概览”，在“当前配置”中选择这份订阅生成的配置。

如果同步失败，先按[订阅管理](./subscriptions)检查，不要在没有有效配置时继续连接。订阅链接可能带有访问凭据，不要公开分享。

有本地文件时，打开“配置 → 新建配置”，选择 Zero JSON 文件，或粘贴 JSON。保存时“设为当前”，也可回到概览选择它。其他客户端的配置不一定能直接导入；Clash 订阅应从订阅入口转换。

**完成标志：概览显示你刚添加的配置名称。** 保存订阅、同步成功与选中当前配置是三个不同步骤。

## 2. 检查概览状态

在专业模式概览点击“检查网络”，查看自测结果或“需关注”提示。先处理以下阻塞项：

- 内核不可用：到“设置 → 版本管理”安装 Zero，或选择已有的可执行文件
- 未选择配置：在概览选择“当前配置”
- 配置无效：查看第一条字段或节点错误，修正配置或重新同步
- 端口占用：到“设置 → 网络”检查代理端口，或关闭占用相同端口的其他代理程序

公网 IP 查询或探测站点失败，不一定表示代理不能用；下一步仍需用自己的目标网站验证。

## 3. 开启服务

1. 在概览的“内核状态”卡片点击“开启系统代理”。客户端会准备当前配置、启动或连接 Zero，并等待本地代理端口就绪。
2. 确认系统代理已开启，内核不再显示“启动失败”或“状态待确认”。
3. 如果当前配置有策略组，在概览选择出口，或到“节点”页选择可用节点。
4. 打开浏览器，访问你实际需要的网站。

**完成标志：系统代理已开启，目标网站可访问。** 测速数字、公网 IP 查询和流量曲线都只是辅助信息。无法访问时，按[已连接但应用没有走代理](./troubleshooting#已连接但应用没有走代理)检查。

Linux 的系统代理集成使用 GNOME `gsettings`。其他桌面环境或不遵循系统代理的应用，可手动填写概览显示的本地 HTTP/SOCKS5 地址，详见[本地代理入口](./proxy-and-probes#本地代理入口)。

## 4. 按需启用 TUN

浏览器已经可用，但游戏、命令行或其他应用仍未走代理时，再考虑 TUN。它创建虚拟网卡并调整路由，需要系统权限；不是第一次连接的必选步骤。

在专业模式进入“设置 → 流量接管”，按 [TUN 指南](./tun)配置。需要 DNS 劫持时，先按 [DNS 指南](./dns)保存解析设置。开启后检查 TUN 的实际运行状态，再验证目标应用。

**简约模式不同：概览中央的电源按钮同时开启系统代理和 TUN，关闭时也会关闭两者。** TUN 无法启动时，整个连接操作可能失败并尝试恢复；若只想用系统代理，继续使用专业模式的独立开关。

## 5. 切换配置

专业模式在概览的“当前配置”中切换；简约模式在“配置来源”中选择订阅。切换完成后重新检查当前名称、所选节点和网站访问。

当前候选版中的 DNS、代理端口、TUN 等本地修改只属于正在编辑的配置。切换配置不会把这些修改自动复制过去。若提示新配置的 TUN 参数与运行中不一致，先关闭 TUN，再切换并重新开启。

## 6. 关闭服务

- 专业模式：点击“关闭系统代理”；如果另行启用了 TUN，也要单独关闭
- 简约模式：点击中央电源按钮，关闭系统代理和 TUN，并取消 TUN 自动恢复

等待界面确认关闭。Zero 进程可能继续运行以保留监控和管理能力；进程仍在不代表流量仍被接管。若显示状态未知或关闭失败，按[故障排查](./troubleshooting)处理。

## 7. 选择节点与模式

在概览选择规则、全局或直连：规则模式按配置分流，全局模式使用全局代理出口，直连模式直接访问目标。可选模式由当前配置和内核决定。

到“节点”页选择策略组，再选择其中的节点。自动选择的 URLTest 组由内核决定成员；需要手选时选择支持手动切换的组。测速用于检查响应延迟，不代表下载带宽；详细步骤见[节点与 URLTest 测速](./proxy-and-probes#节点与-urltest-测速)。
