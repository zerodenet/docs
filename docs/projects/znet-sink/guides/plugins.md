# 安装与管理插件

插件为 ZNet Sink 增加额外服务和工具。普通订阅和代理连接不要求安装插件。

插件运行入口用于桌面端，Android/iOS 尚未开放；每个插件还会检查客户端版本、系统和架构是否兼容。没有插件入口时，先检查客户端是否支持该功能。

## 从插件市场安装

1. 打开“插件”，点击“安装插件”。
2. 在市场选择需要的插件，核对名称、发布者、用途和兼容版本。
3. 保留正式版渠道，或明确选择你需要测试的候选/开发渠道。没有兼容发行包时不能安装，不应下载其他平台的包强行尝试。
4. 点击安装，等待下载、完整性和签名校验结束。
5. 点击“检查权限并启用”，继续完成配置与授权。

市场提供登记和版本信息，安装包直接来自作者的 GitHub Release。目录为空与目录加载失败不同；先看提示，再决定刷新或检查网络。市场登记、签名或下载成功都不代表插件适合你，也不代表它已经获得运行权限。

## 从本地安装

在安装窗口点击“从本地安装”，选择来源可信的 `.zspkg` 文件。阅读插件 ID、发布者公钥指纹、版本、权限和页面声明，确认后才点击“信任并安装”。未上架市场的包也可以走这一流程。

本地首次信任由你负责核实来源。后续更新需要沿用同一签名身份；遇到身份不符或校验失败时，向发布者确认，不要为绕过错误直接卸载重装。

## 配置、授权并启用

1. 打开已安装插件的详情，在“管理”中完成它要求的服务地址等配置。
2. 转到“权限”，检查每项功能及具体访问范围。先使用“仅选必需”，再按需要增加可选权限。
3. 点击“允许并启用”。如果按钮不可用，先处理缺失配置、必需权限或“不支持”提示。
4. 回到“管理”使用插件提供的功能；登录、绑定账号或同步由具体插件说明。

“已安装”“已授权”和“已启用”是不同状态。权限由客户端固定界面显示；包安装确认不等于允许它读取数据或访问服务。一个插件可以含多个组件，应分别检查权限。

签名用于核对包和发布者身份，不等于安全保证。只启用信任的插件，并检查网络目的地址、文件、凭据或托管订阅等访问范围。

## 更新插件

点击“检查已安装插件”，有更新时打开“查看更新”或市场中的“版本管理”，选择兼容版本并下载。

权限或范围增加时，需要先确认安装包变更，再到权限页批准实际运行权限。看到“暂未启用”时先完成这一步。更新检查不是自动安装，当前没有一键回退界面；安装旧版本会被阻止。

确需回退时，先核对卸载影响并保留可恢复信息。不要把“卸载后装旧版”当作不会丢数据的操作。

## 停用、撤权和卸载

- **停用**：在插件详情关闭启用开关，停止组件使用
- **撤权**：在“权限”中点击“撤销已批准权限”，以后使用时需要重新确认
- **卸载**：在“关于”中卸载，并仔细阅读确认对话框

::: warning 卸载会影响托管来源
卸载会删除插件组件、配置、状态、缓存和已批准权限，也会删除它托管的订阅、关联配置和规则。正在使用其配置时，客户端会尝试切换到剩余配置；没有可用配置时会停止代理。
:::

如果只是临时不用，优先停用，不要用卸载排查每一种运行错误。

## 插件不能用时

- 没有插件入口：先检查客户端是否支持插件；旧版没有此入口
- 没有兼容包：检查所选渠道、客户端版本与平台，不等于整个插件市场故障
- 已安装但未启用：检查配置、必需权限和权限变更提示
- 页面只显示基础配置或开发诊断：该包可能没有提供完整业务管理页面，不能把诊断成功当成账号登录或订阅接入成功
- 更新签名或身份错误：保留错误信息并联系发布者，不要跳过校验

反馈时附上客户端版本、插件 ID/版本、操作和首条错误；不要公开账号凭据、令牌、完整订阅或私人配置。开发插件的包格式和项目规范见[贡献入口](../contributing/)。
