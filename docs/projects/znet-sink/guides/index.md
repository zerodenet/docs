# ZNet Sink 用户指南

如果刚安装，先完成前两步；其余页面按遇到的问题查阅。

1. [安装与首次启动](./installation)：安装客户端和 Zero 内核
2. [完成第一次连接](./first-connection)：添加来源、选中配置、开启系统代理并验证
3. [订阅管理](./subscriptions)：更新节点、选择当前订阅、处理同步失败
4. [本地代理、系统代理与节点测速](./proxy-and-probes)：切换节点，让指定应用使用代理
5. [功能总览](./features)：找到各项操作入口
6. [数据与诊断](./data-and-diagnostics)：查看连接与日志，导出排障材料
7. [故障排查](./troubleshooting)：按现象恢复连接

本指南按[文档适用版本](../#文档适用版本)核对。设置入口使用界面中的“应用 / 版本管理 / 域名解析 / 流量接管 / 高级配置”；本地代理端口在“网络”。插件及当前配置的本地修改与 0.0.1 正式版不同。

## 设置专题

- [DNS 与 Fake-IP](./dns)：改变解析方式，处理内网域名
- [TUN 接管与网络切换](./tun)：接管不遵循系统代理的应用
- [迁移设置与管理内核](./settings-transfer)：保留本地修改，升级和换电脑
- [安装与管理插件](./plugins)：检查来源、权限、更新及卸载影响
