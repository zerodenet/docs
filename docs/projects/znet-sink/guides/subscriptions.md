# 订阅管理

订阅用于从服务提供方更新节点和配置。你需要自行取得有效的订阅链接；ZNet Sink 不提供节点。远程订阅、同步生成的本地配置和当前使用的配置是三个不同概念。

## 支持的格式

添加订阅时选择“自动检测”“Zero”或“Clash”：

- **Zero**：Base64 编码的 Zero JSON；远程明文 Zero JSON 会被拒绝
- **Clash**：当前支持的 YAML 或 Base64 YAML；转换不保证兼容所有 Clash 扩展
- **自动检测**：从本次响应识别上述格式，通常优先选它

已有普通 Zero JSON 文件时，切到专业模式，从“配置 → 新建配置”导入，不要把它当作远程订阅。Base64 只是编码，不会隐藏节点地址或凭据。

## 添加订阅

1. 打开“订阅”，点击“新增”，填写名称和 URL。
2. 保留“自动检测”；只有服务提供方明确指定格式时再修改。
3. 关联配置通常选择自动创建；按需要设置自动同步间隔，保持订阅启用。
4. 保存后点击该订阅的同步按钮，等待显示最近同步时间或成功提示。
5. 专业模式回到概览选择“当前配置”；简约模式在概览“配置来源”中选择该订阅。

**完成标志：同步成功，概览显示所选来源或配置。** 禁用订阅表示暂停参与批量和定时同步，不等于自动关闭当前代理。

当前候选版中的插件托管订阅由来源插件刷新和管理。如果卡片显示“插件托管”，请回到相应插件完成登录、授权或刷新，不要尝试把它改成普通链接订阅。卸载来源插件会删除其托管订阅及关联配置，详见[插件指南](./plugins)。

## User-Agent

留空时发送 `ZNet-Sink/<当前版本>`，例如 `ZNet-Sink/0.0.1`。自定义值会完全替换默认值。

使用 Zboard 的普通公开订阅链接时，通常保持留空，因为接口要求 `ZNet-Sink/<版本>` 格式。其他服务明确要求专用 User-Agent 时再填写。插件登录或受保护托管来源按该插件的说明使用，不能假定普通订阅链接能替代它。

## 本地代理入口

订阅生成的配置需要可供应用连接的本地代理入口。没有相应字段时，客户端可以补齐默认 Mixed 入口 `127.0.0.1:7890`；配置已有有效入口时保留来源值。

当前候选版尊重显式空的 `inbounds: []`，不会把“明确不创建入站”当成字段缺失。若提示缺少本地入口，检查来源配置或使用提供有效本地入口的配置，不要假定同步必然补齐一切。

在“设置 → 网络”调整代理端口。当前候选版会把修改保存在当前配置下，其他配置不跟随改变。详见[本地代理入口](./proxy-and-probes#本地代理入口)。

## 同步语义

- 手动同步拉取远端最新内容；启用自动同步后按所选周期更新
- 单次网络或解析失败不应被当成成功内容覆盖原有可用配置；失败时保留错误供排查
- 同步后检查节点和规则，特别是从 Clash 转换时
- 当前候选版保留你对该配置所作的本地设置修改；如要重新跟随来源，使用相应设置中的“恢复配置值”
- 更新改变正在运行的 TUN 参数时，按提示先关闭 TUN，再同步或切换并重新开启

删除普通订阅时，界面会让你确认是否保留关联配置。删除当前使用的配置可能导致切换配置或停止代理，应先阅读确认内容。

## Base64 响应

同步得到网页、登录页、重定向错误、明文 Zero JSON 或无效 Base64 时，先核对链接是否过期、服务是否需要特定 User-Agent，以及服务端输出格式。

“自动检测”不能把普通网页变成订阅。反复切换格式或测速不会修复失效的订阅令牌；必要时向服务提供方重新获取链接。

## 安全提示

订阅 URL 可能相当于访问凭据。不要把完整 URL、节点密码或配置原文放入公开问题和截图。日志或诊断包在发送前也要自行检查。
