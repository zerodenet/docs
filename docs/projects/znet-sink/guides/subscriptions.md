# 订阅管理

订阅由 ZNet Sink 拉取、解析并转换成本地代理配置。订阅记录和生成的配置都保存在客户端本地。

## 支持的格式

当前支持：

- Zero JSON
- Zero Base64 JSON
- Clash YAML
- Clash Base64 YAML
- 自动检测上述格式

Clash 内容会转换为 Zero 配置。转换能力不等同于完整兼容所有 Clash 扩展字段；同步完成后仍应检查生成的节点、策略组和规则。

## 添加订阅

1. 打开“订阅”。
2. 点击新增订阅，填写名称和订阅 URL。
3. 通常保留“自动检测”；只有服务端格式固定且检测失败时再手动指定。
4. 根据需要选择手动更新或 30 分钟、1 小时、6 小时、12 小时、24 小时的更新周期。
5. 保存并执行同步。

同步成功后，订阅会创建或更新一份本地代理配置。新生成的配置不会无条件抢占当前配置；需要时请在“配置”页确认并启用。

## 同步语义

- 禁用订阅后，不参与批量和定时同步。
- 手动同步会立即拉取远端内容。
- 同步失败会保留错误信息，原有可用配置不会因为一次网络失败被当作成功结果覆盖。
- Clash `rule-providers` 和引用它们的规则会按客户端当前支持边界转换为本地规则集。

## 安全提示

订阅 URL 可能包含访问凭据。不要把完整 URL 放进公开问题、截图或普通日志。导出的诊断包会排除订阅地址，但发送前仍应自行复核内容。
