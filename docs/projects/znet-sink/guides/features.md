# 功能总览

先按[第一次连接](./first-connection)完成可用连接，再按任务找入口。

## 配置与连接

有订阅链接，使用“订阅 → 新增 → 同步”；有 Zero JSON 文件，切到专业模式，在“配置 → 新建配置”导入。随后在概览选中当前配置，再开启代理。

配置保存成功不代表已经连接。概览中的内核状态、系统代理和 TUN 分别表示不同环节，应以实际网站或应用访问结果验证。

## 内核与代理开关

- **Zero 内核**：负责实际转发；在“设置 → 版本管理”安装和选择
- **系统代理**：供遵循系统代理设置的应用使用；专业模式可以独立开启或关闭
- **TUN**：接管进入虚拟网卡的流量，需要额外权限；专业模式可以独立控制
- **简约模式电源按钮**：同时开启或关闭系统代理和 TUN；关闭后内核仍可保持运行

只切换简约/专业模式不会改变已有运行状态。不要把“内核监听中”当成系统代理或 TUN 已开启。

## TUN 与 DNS

“设置 → 域名解析”管理 Real DNS、Fake-IP、上游和分流；专业模式的“设置 → 流量接管”管理 TUN 地址、接管网段和 DNS 劫持。“设置 → 网络”管理本地代理端口和统一绕过规则。

设置页显示“来自配置”或“本地修改 · 仅当前配置”。保存修改只影响当前配置，订阅更新仍保留修改；“恢复配置值”重新采用来源的最新值。具体操作见 [DNS](./dns)、[TUN](./tun)和[设置迁移](./settings-transfer)。

## 订阅管理

保存 Zero 或 Clash 订阅，手动或定时同步。同步结果会更新关联配置；新来源不会仅因为保存成功就自动成为当前来源。Zero 远程订阅要求 Base64 编码的 Zero JSON；普通本地 JSON 文件则从配置页导入。

新版还可显示插件托管的订阅；登录、刷新或取消托管请在来源插件中操作。详见[订阅管理](./subscriptions)。

## 节点与策略

在“节点”选择策略组、切换可手选的节点，并对当前目标测速。URLTest 自动组由内核选择出口；卡片上的延迟不是下载速度。

节点页还可显示配置中的 WireGuard 端点。它们能用于配置指定的路由或 DNS；查看端点不会自动将它设为某个策略组成员。详见[节点与测速](./proxy-and-probes#节点与-urltest-测速)。

## 规则分流

专业模式的“规则”页管理规则集、顺序和分流动作。需要某个域名或网段直连时，先判断应修改路由规则，还是使用[统一绕过规则](./proxy-and-probes#统一绕过规则)保留局域网访问。

规则模式按配置分流；切换全局模式不会抹掉已有规则。规则页中的更新成功也不代表每个目标都命中了预期规则，可在连接详情中核对实际出站。

## 桌面代理集成

Windows、macOS 和 Linux 具有各自的系统代理实现，目标应用仍需遵循这些设置。Linux 当前使用 GNOME `gsettings`；其他桌面环境可能需在应用中手动配置本地 HTTP/SOCKS5 代理。

Windows 托盘的“打开终端”可创建带代理环境变量的 PowerShell；变量只作用于该终端及子进程。操作步骤见[本地代理与系统代理](./proxy-and-probes)。

## 界面模式

- **简约模式**：集中显示概览、节点、订阅、日志和设置；支持插件的版本也显示插件入口
- **专业模式**：增加静态配置、规则、连接和调试，以及 TUN 细项等高级设置

先按你需要控制的范围选择模式。只想开启系统代理，使用专业模式；希望一个按钮同时管理系统代理和 TUN，可使用简约模式并准备相应权限。

## 版本与运行环境

客户端和内核分别更新。版本列表有更新，不代表当前使用的内核已经更换。更新后在“设置 → 版本管理”核对实际路径与版本，再验证连接。

侧栏提供插件入口时，可按[安装与管理插件](./plugins)扩展功能。安装成功后仍需确认运行权限；具体插件可能限制客户端版本、平台和架构。

## 日志与诊断

连接失败时先看最早出现的错误。日志页可按来源和关键词筛选；专业模式还可查看活动连接和详细诊断。需要反馈时，按[数据与诊断](./data-and-diagnostics)导出并检查资料，再附上客户端、内核和系统版本。
