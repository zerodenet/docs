# 参与 ZNet Sink

本页只说明如何参与 ZNet Sink 项目。问题、代码评审、发布和行为决策均由 ZNet Sink 仓库维护。

## 反馈问题

提交问题前，请先搜索 [ZNet Sink Issues](https://github.com/zerodenet/znet-sink/issues)，并准备以下信息：

- 客户端版本、操作系统和架构；
- 最小复现步骤与预期行为；
- 首个相关错误和经过脱敏的诊断信息；
- 问题是否能在当前稳定版复现。

不要公开订阅地址、代理凭据、访问令牌或包含私人流量信息的日志。

## 贡献代码

代码变更从 [ZNet Sink 仓库](https://github.com/zerodenet/znet-sink) 发起。提交拉取请求时，请说明用户可见变化、验证范围和已知限制；涉及界面行为时，同时检查桌面与窄屏窗口下的交互。
