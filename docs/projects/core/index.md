# Zero Core

<ProjectMeta project-id="core" />

Zero Core 是一个命令行代理程序。它用 JSON 配置接收应用连接、选择直连或远程代理，并处理分流、DNS 和 TUN 流量。

## 第一次使用

从[第一次使用 Zero Core](./guides/quickstart)开始：在一页内完成下载、配置、第一条代理请求和停止。无需远程服务器或管理员权限。

如果你更想通过界面导入订阅、切换节点和开关系统代理，请在[项目选择](/projects/)中选择 ZNet Sink。
