# 项目如何配合使用

每个项目解决一层问题。先选择符合自己需求的最小组合，连接成功后再增加管理或接管能力。

## 桌面代理

**已有订阅 → ZNet Sink → 本机 Zero Core → 代理节点**

ZNet Sink 帮你添加订阅、切换节点和设置系统代理，并管理本机的 Zero Core。订阅由你自己的面板或服务提供方提供，客户端不附带代理节点。

按[第一次连接教程](/projects/znet-sink/guides/first-connection)操作即可，不需要部署 ZBoard。浏览器能用后，再按需要开启 TUN 接管其他应用。

## 运行节点

**应用或客户端 → Zero Core → 目标网站 / 远程代理**

Zero Core 可以独立运行。配置文件中的入站接受连接，出站决定请求往哪里走，路由决定哪些请求使用哪个出口。

先按[运行第一个代理](/projects/core/guides/quickstart)验证本机请求；需要远程节点时再[添加代理出站](/projects/core/guides/configuration-basics)。不需要图形界面或账户管理时，仅运行 Core 即可。

## 自用与分享 {#服务运营}

**ZBoard 管理用户和线路 → 节点上的 Zero Core 接收配置 → 用户把订阅导入客户端**

ZBoard 保存谁可以使用哪些线路、可用时间和流量额度；节点上的 Core 验证凭据、转发请求并上报用量。客户端通过订阅取得被授权的连接信息。

按[从部署到第一条可用线路](/projects/zboard/guides/)完成整条链路。面板显示节点在线之后，还要在客户端发起真实请求，确认用量返回。自用或免费分享不需要接入支付插件。

## 应用集成

自己的脚本、界面或控制服务也可以通过 Core 的控制接口读取状态、选择出站和应用配置。从[控制 API 使用说明](/projects/core/guides/control-api)开始，按使用到的接口查参考即可。

## 常见组合

- **只有一个现成订阅：** ZNet Sink 管理本机 Zero Core
- **自己维护一个配置文件：** 直接运行 Zero Core
- **统一管理多个节点或分享账户：** ZBoard 管理节点，使用者选择自己的客户端

这些项目分别管理不同的数据。备份客户端设置不能代替备份面板数据库；更新面板也不会自动更新每台电脑里的内核。升级时按[各自的恢复步骤](/progress)操作。
